# Contributing

Bug reports and feedback on the language are welcome as GitHub issues or
discussions. This repository is published from a separate development tree, and
each release replaces its contents, so **it does not accept pull requests**.

## Suggesting enhancements

Suggestions for enhancements, including design and implementation ideas,
feature requests, and tooling or ecosystem expansion, are most welcome.
Please submit them in the
[discussion board](https://github.com/codemartial/ritchie/discussions).

## Reporting a problem

Problems are reported as
[issues](https://github.com/codemartial/ritchie/issues). A report states:

- the smallest complete Ritchie program that shows the problem,
- what the program does today, including the full compiler or runtime
  output,
- what it should do, with the section of the
  [language reference](docs/ritchie-reference.pdf) that says so when one
  applies,
- the commit of this repository, the Go version, and the operating system.

## Questions about the language

Questions go to the
[Q&A category](https://github.com/codemartial/ritchie/discussions/categories/q-a)
of the discussion board. A question about the meaning of a form cites the
section of the language reference that it concerns. The
[skill](skill/SKILL.md) describes the subset that the compiler implements
today, so a program outside that subset is a feature request rather than a
bug, which goes to the discussion board as
[an enhancement](#suggesting-enhancements).

## Security

Vulnerabilities may be reported privately through the Security tab of this
repository. Please do not create a public issue for vulnerability reports.
